# Tic-Tac-Toe (Python)

A two-player tic-tac-toe game with a graphical board, built with Python and pygame.

## Features
- Two players take turns as X and O
- Detects wins and draws
- Highlights the winning line
- Resets automatically after each round

## How to run
1. Install Python 3
2. Install pygame: `pip install pygame`
3. Run: `python tictactoe.py`
